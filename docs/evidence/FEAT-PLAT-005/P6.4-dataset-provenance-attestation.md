# P6.4 Dataset Provenance Attestation

Status: ATTESTED (2026-09-19)

This attestation implements the synthetic-only policy approved and signed in
`ci/dor/P0.5-dataset-provenance.json`.

1. The stage-12 dataset is generated exclusively by
   `DeterministicDatasetGenerator` from the committed
   `migration/volumetrics.yaml` profile, an integer seed, and a scale.
2. Its value strategies are deterministic sequences, UUIDs, bounded integers,
   fixed constants, and synthetic tokens. The profile contains no name, email,
   telephone, address, candidate identifier, answer content, or other personal
   data source.
3. The `generate-dataset` command accepts only a profile path, output path,
   optional seed, and optional scale. It reads no JDBC URL, database credential,
   hostname, environment selector, dump, snapshot, or external service input.
4. The generator has no `java.net`, `java.sql`, R2DBC, HTTP, socket, or process
   API import. Its only reads are the committed profile and its own generated
   output for checksumming. It therefore has no code path to a production
   database.
5. `verify-dataset-provenance-approval` validates the signed prohibition on
   production extracts, dumps, snapshots, personal data, and production-derived
   seed data before stage 12 runs.

Changing the generator inputs, introducing a production connector, or enabling
production-derived data invalidates this attestation and requires the new
privacy and architecture review mandated by P0.5.
