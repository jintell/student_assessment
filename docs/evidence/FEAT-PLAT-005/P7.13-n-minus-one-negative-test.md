# P7.13 N-1 Breaking-Change Negative Test

Status: RETAINED FAILURE EVIDENCE (2026-09-21)

`NMinusOneBreakingChangeIntegrationTest.droppedColumnReadByPreviousReleaseFailsCompatibilityGate`
creates `platform.migration_fixture` with the legacy `obsolete_value` column in
an ephemeral PostgreSQL 17 database, inserts a previous-version row, and then
applies the deliberately breaking operation:

```sql
ALTER TABLE platform.migration_fixture DROP COLUMN obsolete_value;
```

The previous-version compatibility case then executes its retained read of
`obsolete_value`. PostgreSQL rejects that read, the case reports
`existingReadPassed=false`, and `NMinusOneCompatibilityRunner` blocks the
release with:

```text
N-1 compatibility case failed: previous-release-obsolete-column-read
```

The breaking change exists only inside the disposable test database. The
committed release migration remains the additive
`V7__expand_migration_fixture.sql`; no applied migration was edited and no
schema rollback was performed.
