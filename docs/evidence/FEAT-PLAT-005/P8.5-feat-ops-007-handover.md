# FEAT-OPS-007 Migration Interface Handover

Status: **READY FOR CONSUMPTION**

## Deploy-freeze precondition

`FEAT-OPS-007` must call `DeployFreezePrecondition.evaluate(environment,
decisionTime)` before creating the migration Job. The returned contract is:

| State | `permitted` | Exit | Required orchestration action |
|---|---:|---:|---|
| `NONE` | `true` | `0` | Continue to the migration Job. |
| `OPEN` | `false` | `20` | Block the deploy; an emergency override requires the governed two-approval path. |
| `UNKNOWN` (`SOURCE_UNKNOWN`) | `false` | `21` | Block the deploy as fail-closed; do not reinterpret source failure as no session. |

An empty result, timeout, or source error becomes `UNKNOWN`. The orchestration
must retain the returned window reason and must not add an environment-variable
or pipeline-flag bypass.

## Release manifest

Consume the successful stage-12 artifact
`migration-release-manifest-<commit-sha>`. Verify its artifact provenance and
checksum before reading these required fields:

- `release`
- `classification`: exactly one of `EXPAND`, `MIGRATE`, or `CONTRACT`
- `previousImageDigest`: immutable `sha256` digest
- `migrationSetChecksum`
- `migrations`: the checksummed migration entries

The manifest passed the classification gate before publication. A missing,
unreadable, or checksum-mismatched manifest blocks deployment and rollback.

## Rollback policy

Create `RollbackRequest` from the validated manifest and call
`RollbackPolicy.evaluate` before changing a workload image.

| Decision | Exit | Required orchestration action |
|---|---:|---|
| `CODE_ROLLBACK_PERMITTED` | `0` | Deploy only the retained N-1 image digest; do not run a migration or schema undo. |
| `CONTRACT_ROLLBACK_FORBIDDEN` | `30` | Halt, reference an incident, and prepare a reviewed forward-fix migration. |
| Invalid digest or non-green N-1 evidence | `31` | Refuse rollback until matching compatibility evidence is green. |

The `CONTRACT` refusal applies to automatic, manual, and emergency-override
paths. An override may address only the session freeze; it cannot bypass the
manifest, stage 12, compatibility evidence, or rollback policy.
