# P6.8 ARC-RISK-017 Conformance Record

Status: CONDITIONALLY CONFORMANT (2026-09-19)

`ARC-RISK-017` is the High-impact, Low-likelihood risk that a migration lock
stalls the exam path during a release. Architecture section 22.2 defines four
mitigation limbs. This review maps each limb to its implemented control and
names the remaining downstream proof without treating it as complete.

| Architecture mitigation | Implemented control | Evidence state |
|---|---|---|
| Expand/contract only | Mandatory phase headers, the closed phase-specific DDL allowlist, one release classification, `EXPAND` plus `CONTRACT` mix refusal, N-1 compatibility runner, and `CONTRACT` rollback refusal | Implementation and unit evidence present; release compatibility execution remains a stage-12/Phase-7 obligation |
| `CREATE INDEX CONCURRENTLY` mandatory | `NonConcurrentIndexCheck` and `ClosedDdlAllowlist` independently reject a normal index build; concurrent index scripts must be non-transactional | Implementation and unit evidence present; live concurrent-index behavior is proven by P7.7 and P7.9 |
| CI lock-duration gate against production-shaped data | Signed synthetic-only volumetric profile, deterministic generator, pinned PostgreSQL 17 container, 10 ms `pg_locks` sampler, exact lock-mode threshold policy, approved 100/250/2000 ms bounds, lock report emitter, and blocking stage-12 entrypoint | Components present. P7.6-P7.8 and P7.11 must still prove the integrated gate detects a real violation, avoids a concurrent-index false positive, enforces timeout, and passes the full migration set |
| Deploys blocked while a session is open (`ARC-OPS-013`) | `SessionWindowQuery` port, fail-closed `UNKNOWN` adapter, bounded `DeployFreezePrecondition`, stable non-zero refusal codes, refusal telemetry, and two-person audited emergency override | Implementation and unit evidence present; stages 19/20 deployment orchestration remains owned by `FEAT-OPS-007` |

The preventive lock-timeout limb reduces exposure even before detective CI
evidence: migration sessions apply bounded `lock_timeout`, `statement_timeout`,
and `idle_in_transaction_session_timeout` values. Static analysis also rejects
row-modifying SQL, so accepted answers cannot be changed through a disguised
migration.

The risk remains conditionally conformant until the named Phase 7 live tests
and `FEAT-OPS-007` deployment wiring are green. None of those conditions may be
converted to an advisory check or bypassed by the emergency override.
