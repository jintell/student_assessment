# P3.9 Migration Job Envelope Input

| Field | Value |
|---|---|
| Feature | `FEAT-PLAT-005` |
| Architecture control | `ARC-PERF-006` |
| Envelope term | `migration_job` |
| Connection allowance | 10 |
| Lifetime | Transient; present for every release migration |
| Workload identity | `cbt-platform-migration` service account using `app_migrator` |
| Runtime configuration | `CBT_MIGRATION_CONNECTION_ALLOWANCE=10` |
| Resource template | `deploy/kubernetes/migration-job.yaml.template` |

The connection envelope must include all ten migration connections at baseline
and at simultaneous workload scaling ceilings. Capacity verification that omits
the active Job does not satisfy condition `A8` or `ARC-VERIFY-033`.

The release pipeline must replace `CBT_PLATFORM_IMAGE_DIGEST` with the same
immutable signed image digest used for the other workloads. The template is not
a deployable artifact until that substitution and manifest validation succeed.
