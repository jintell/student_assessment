## ARC-PERF-006 Report

Using 20 operations connections, 10 PostgreSQL internal/reserved connections,
40 funded headroom connections, a 10-connection migration Job, and
`max_connections = 750`:

| Operating point | `allocated` | `allocated_with_headroom` | `committed` | `headroom_remaining` |
|---|---:|---:|---:|---:|
| Baseline | 268 | 308 | 318 | 432 |
| Simultaneous workload ceilings | 700 | 740 | 750 | 0 |

Definitions match the architecture contract:

- `allocated` includes workload pools, operations, and PostgreSQL
  internal/reserved connections, but excludes funded headroom and the
  migration Job.
- `allocated_with_headroom` adds 40 funded headroom connections.
- `committed` adds the 10-connection migration Job.
- `headroom_remaining` is `max_connections - committed`.

The ceiling inequality is exactly funded: `750 >= 750`. A deterministic
arithmetic check reproduced all eight reported values on 2026-09-27.
