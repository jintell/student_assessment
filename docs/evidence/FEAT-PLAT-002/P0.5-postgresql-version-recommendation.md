# P0.5 PostgreSQL Version Recommendation

**Date raised:** 2026-09-09<br />
**Decision status:** APPROVED<br />
**Decision owner:** Architecture Owner<br />
**Tracking ID:** `TASK-PLAT2-DEFECT-005`

## Recommendation

Approve PostgreSQL 17 as the persistence baseline for local development, CI,
staging, and production. Persistence task `P3.1` will pin one reviewed image
digest across local development, CI, and staging so the version is not resolved
from a mutable tag at runtime.

## Rationale

The architecture depends on version-sensitive PostgreSQL behavior, including
`current_setting(..., false)`, forced row-level security, transaction-local
settings, and transaction-scoped advisory locks. A named major version is
required before migrations and integration tests can provide repeatable
evidence for those controls.

PostgreSQL 17 is already the documented feature recommendation and the planned
Testcontainers substrate. Approving it avoids introducing a second version
assumption during Phase 3.

## Decision

The Architecture Owner approved PostgreSQL 17 in
`docs/decisions/P0.5-postgresql-version-approval.md`. The approved immutable
image is declared by `postgresqlImage` in `gradle.properties` and enforced by
the `verifyPostgresqlBaseline` CI gate.

Any major-version change requires a new Architecture Owner decision and the
compatibility validation named in that approval record.

## Verification

`./gradlew verifyPostgresqlBaseline` passed on 2026-09-09. The gate verified:

1. the approved Architecture Owner decision;
2. PostgreSQL major version 17;
3. the immutable `sha256` image digest;
4. the Testcontainers image;
5. the CI service image;
6. absence of the mutable latest tag; and
7. absence of a conflicting PostgreSQL major version.

The same run started the approved image and verified the reported server major,
missing-context failure, transaction-local context reset, and forced-RLS tenant
filtering behavior.
