The signed `P3.5` collector contract resolves the application integration
boundary and names Platform Ops for the deployed collector and stores. It
does not repair the plan's missing feature ownership for selecting, building,
operating, capacity-testing, or releasing that backend product. The defect
therefore remains visible until the plan assigns that lifecycle explicitly.

No deferral permits a published metric or field to be removed, telemetry
failure to affect request availability, a secret to enter telemetry, or an
unowned dashboard/alert to be represented as live.
