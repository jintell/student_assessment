# FEAT-OBS-001 Self-Health Alert Proposals

Status: **HANDED TO FEAT-OPS-004; THRESHOLDS PENDING CALIBRATION**

Both alerts are P2 proposals. `FEAT-OPS-004` owns final thresholds, `for`
durations, routing, maintenance suppression, deployment, and synthetic
exercise evidence. Their data source must read the local registry or Actuator
health component independently of the OTLP export path being monitored.

## TelemetryExportFailureRateSustained - P2

Intent: detect a sustained fall in acknowledged exports for any signal while
attempts continue.

Candidate recording expression:

```promql
1 - (
  sum by (signal) (rate(telemetry_export_success_total[10m]))
  /
  clamp_min(sum by (signal) (rate(telemetry_export_attempt_total[10m])), 1)
)
```

The rule should require non-zero attempt volume and a calibrated sustained
failure ratio. It should correlate timeout and signal-specific drop counters
and queue depth/capacity. It must not alert on an idle process with no export
attempts.

Severity: **P2**.

First action: **check the collector and confirm no request-path impact**.
Inspect the local `observability` health component, queue depth/capacity,
timeouts, and drop reason for the affected signal. Confirm liveness,
readiness, request success, and latency remain healthy before working outward
through DNS, mTLS identity, collector gateway, and backend capacity.

## TelemetryRedactionRejectionRateSustained - P2

Intent: detect a new or growing code path attempting to emit a prohibited or
unserializable telemetry field.

Candidate expression:

```promql
sum by (surface, reason) (
  rate(telemetry_redaction_rejection_total[10m])
) > 0
```

`FEAT-OPS-004` must calibrate the sustained window without weakening the
fail-closed redactor. The alert retains only the closed `surface` and `reason`
labels; it must never attach the rejected field name or value.

Severity: **P2**.

First action: identify the newly deployed or newly exercised emission path,
reproduce it with the telemetry hygiene gate, and remove or replace the
prohibited field. Do not relax the secret pattern, add a broad `*_key`
allowance, log the rejected value, or silence a sustained rejection as noise.

## Exercise Contract

Before launch-condition `L5` closes, inject one exporter failure and one
synthetic prohibited field, prove each alert routes as P2 with the first
action above, retain notification evidence, then prove recovery after a
successful export or removal of the rejected field.
