# P8.5 Shared-Kernel Interface Handovers

Status: **PUBLISHED FOR CONSUMPTION**

This record publishes the stable interfaces delivered by `FEAT-PLAT-003` and
keeps each downstream implementation responsibility with its owning feature.

| Consumer | Published interface | Consumer obligation | Verification input |
|---|---|---|---|
| `FEAT-PLAT-004` | Framework-free `OutboxWriter`, `OutboxMessage`, `IntegrationEvent`, `AggregateReference`, typed aggregate/event identifiers, and originating `CorrelationId` | Implement the `outbox.outbox_event` adapter on the caller's transaction; preserve the correlation identifier; do not introduce a second asynchronous publication path | R7/R8 conformance and transactional outbox integration tests |
| `FEAT-AUD-001` | Immutable `ActorContext`, `ActorType`, `ActorId`, closed `SystemActor`, tenant and correlation identifiers, and `SecretFieldPattern` | Require the actor on every audited write, preserve tenant scope, accept only enumerated system actors, and apply the canonical secret-field rule without copying its terms | `ARC-VERIFY-011`, audit coverage, and audit secret-leak scan |
| `FEAT-GRD-001` | `Decimal` conventions: `DECIMAL128` intermediates, exact `BigDecimal` values, canonical `roundHalfUpToWholeNumber`, and documented `NUMERIC(12,4)` / `NUMERIC(9,6)` storage precision | Build the scoring sequence on the canonical primitive; introduce neither binary floating point nor a second rounding helper | Decimal boundary tests and R6 grading purity rule |
| `FEAT-OBS-001` | Strict `CorrelationId`/generator contract, Reactor keys for correlation, actor and tenant context, and `SecretFieldPattern` | Serialize and export the section 16.1 field set, propagate the same correlation value through traces/events, and apply the canonical redaction rule; never consume the raw request header | `NFR-OBS-002` propagation proof and logging secret-leak scan |
| `FEAT-SEC-001` | Generated error catalogue, `ProblemDetailDocument`, sole `ProblemDetailMapper`, response header contract, fixed namespace/type base, and deny-by-default fallback | Exercise the contract across every endpoint and security boundary; compare OpenAPI compatibility and reject any bypass or non-catalogued body | `ARC-VERIFY-013`, problem allowlist, error leak scan, and contract diff |

None of these handovers transfers implementation of the outbox relay, audit
hash chain, scoring pipeline, logging/export stack, dashboards, alert routing,
authorization, or endpoint-wide security suite into this feature.
