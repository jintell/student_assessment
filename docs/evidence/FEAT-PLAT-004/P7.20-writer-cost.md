# P7.20 Writer Cost Measurement

Date: 2026-10-16. Status: **BLOCKED for full acceptance**.

Command: `./gradlew integrationTest --tests '*OutboxWriterCostIntegrationTest' conformanceTest --tests '*AnswerAcceptanceOutboxTests'` — PASS.

The test exercises the production reactive writer, schema validation and tenant context on real PostgreSQL using the approved image. A reference business insert is compared with that same insert plus an outbox append. Twenty warm-up pairs precede 100 measured pairs, alternating execution order, using an R2DBC pool capped at the P1.8 ten-connection ceiling. Durations use a monotonic clock. The transaction timings include commit; append time includes serialization, validation and the database insert, before commit. Test-only connection/statement instrumentation contributes overhead.

|---|---:|

| Propagating transaction p95 | 9.206 ms |
| Outbox append p95 | 2.211 ms |
| Connection acquisitions per business-only / propagating transaction | 1 / 1 |
| Outbox inserts per business-only / propagating transaction | 0 / 1 |

Each operation asserts the acquisition and insert counts. Committed business and outbox row counts are checked independently. Machine-readable observations are regenerated at `build/reports/outbox-writer-cost.json`; timings vary between runs. This is a local sequential mechanism measurement, not a production load or relay concurrency result.

The static `AnswerAcceptanceOutboxTests` rule passes. The event-free reference transaction also issues zero outbox inserts. Neither substitutes for a delivered answer-acceptance handler under representative load.
