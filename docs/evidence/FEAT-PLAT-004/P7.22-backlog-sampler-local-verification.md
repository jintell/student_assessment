# P7.22 backlog sampler local verification

## Implementation and observed results

The worker configuration now assembles the database reader, immutable snapshot,
expiry-aware telemetry and `outbox-backlog` SweepDefinition. The disabled V12
reservation and worker manifest declare the same identity. The existing actor
and secured transaction adapter successfully read both tenants under
`app_outbox_relay:outbox_relay`; missing/mismatched actors are rejected. No new
grants, connection pools, lock permits, scheduling loops or indexes were added.

Local PostgreSQL tests passed all six sampler cases: all four states/two tenants,
future retry eligibility, age growth, empty/drained/future-timestamp snapshots,
security context, database failure, timeout/cancellation cleanup, disabled
collection, and the aggregate plan. The seventh integration test uses the real
runner, registry and session locks, verifies the production manifest, collects
repeatedly beside a failing relay, and releases the existing worker/lock capacity.
Telemetry tests prove startup unknown, monotonic expiry, no false zero or
extended lifetime after failure, complete replacement, restart and old-owner
expiry. Counter/label contracts remain bounded.

The initial lock-contention test exposed that reactive cancellation alone left
database work waiting on the lock. Adding transaction-local `statement_timeout`
made timeout and cancellation release the connection while the lock remains held.
No snapshot is emitted before the managed transaction finishes cleanup.

The management HTTP test exposed a second prerequisite: this Netty factory does
not implement `server.port=-1` as a disabled listener. A worker-only factory now
returns an inert server for -1 and delegates the separate management server to
Netty. The HTTP test checks main port -1, an empty business-route inventory,
unauthenticated scrape 401 and authenticated cached Prometheus exposition 200.
Its Basic credentials are test-only; deployed OAuth2/TLS configuration remains an
Ops prerequisite. Management paths bypass only business admission, not security.

The initial 10,006-row PostgreSQL plan measured 34 ms for the scoped collection
and 4.024 ms aggregate execution (partition sequential scans, 205 shared buffers).
These are local observations, not approved production SLOs. Counting all retained
states cannot use only the PENDING partial index. No new index is justified;
representative retained-volume and contention measurements remain for enablement.
