# Persistence P7.15 amendment record

Recipient: FEAT-PLAT-002 owner (Engineering Lead). Raised by FEAT-AUD-001.
Recorded 2026-10-18 for P10.10; existing approval is distinguished from new
delivery or acknowledgement.

Baseline: INSERT-only default privileges were incorrectly treated as the final
grant set for every future audit object. Adopted resolution: retain the
`app_migrator` default INSERT-only bootstrap, then explicitly revoke inherited
INSERT on anchors and grant only the signed per-table operations. Never add
schema-wide UPDATE/DELETE defaults. Default privileges and final effective
privileges are different assertions.

and subsequent [ADR-011A](../../decisions/ADR-011A-atomic-audit-append.md).
The [persistence task list](../../../tasks/foundation/persistence/tasks.md)

explicit anchor revocations as well as the migration-time grant set.
