## Result

container-backed Stage 12 verifier. The verifier applied the eleven-entry release
manifest, including all ten audit migrations, exactly once against the generated
production-shaped dataset. Its emitted lock-duration report had overall verdict

verdict, and no forbidden-operation finding.

The release-baseline loader excludes every migration in the current release set.
This prevents consecutive migrations from the same module from being applied as
baseline before their measured execution.

## Reproduction

```bash
./gradlew :migration-verify:analyseReleaseMigrations
./gradlew :migration-verify:test \
  --tests 'org.meldtech.migrationverify.measure.Stage12MigrationVerifierTest' \
  --rerun-tasks
```

The container-backed test writes both JSON and Markdown lock reports and asserts
the report verdict, statement count, observed locks, and absence of failed lock
verdicts.
