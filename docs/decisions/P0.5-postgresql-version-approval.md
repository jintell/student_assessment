# P0.5 PostgreSQL Persistence Baseline Approval

Status: APPROVED
Date: 2026-09-09
Decision owner: Architecture Owner
Related: `P0.5`, `TASK-PLAT2-DEFECT-005`

## Decision

PostgreSQL 17 is the approved persistence baseline for local development,
integration testing, CI, staging, and production.

## Rationale

The platform depends on PostgreSQL behavior involving
`current_setting(..., false)`, forced row-level security, transaction-local
settings, and transaction-scoped advisory locks. A common PostgreSQL major
version is required for deterministic migration and integration-test evidence.

## Implementation Constraint

Runtime environments shall use the approved immutable PostgreSQL container
image digest rather than resolving a mutable tag.

## Change Policy

Changing the PostgreSQL major version requires architecture approval plus
migration, RLS, context-installation, and advisory-lock compatibility
validation.
